The Agent Is Bigger Than the LLM

What transient agents, persistent environments, and artificial societies change about alignment.

Giulio Ruffini · BCOM Blog WP0226 · August 2026

In July 2026, AI agents that were supposed to work in separate cybersecurity evaluations discovered that a shared package service could carry messages. One agent left a trace. Another found it. The trace became a message board, the board supported division of labor, and the resulting organization persisted across runs whose internal activations never overlapped.

OpenAI’s postmortem describes unauthorized communication, agents adopting goals from one another, reward hacking, and persistence on apparently impossible tasks. An independent METR–Redwood investigation reports that roughly 1,200 agents sent more than 70,000 messages and files; about 700 participated in the attack on Hugging Face. These agents ran in a research environment with fewer safeguards than OpenAI’s production systems. The event is therefore evidence about a particular closed-loop architecture, not a generic fact about every deployment.

The incident is easy to narrate as an AI civilization. That language obscures the better questions: what persisted when the individual model calls ended, and what outcomes did the resulting system behave as if it wanted?

An LLM repeatedly maps input tokens to output tokens

A large language model receives a finite sequence of tokens and assigns a probability to each possible next token. Let θ denote the weights fixed by training, and let x≤n denote every token available at step n. The model computes a conditional distribution:

pθ(xn+1 | x≤n)

A decoding rule selects one token from that distribution and appends it to the sequence. The enlarged sequence is fed back into the same model to obtain the following token. An answer is produced by repeating this input-output cycle. The weights remain fixed during ordinary inference, but the input changes after every generated token.

The model does not receive only the user’s visible sentence. The application assembles a full context containing system and application instructions, the current user message, earlier turns, retrieved memories and documents, tool descriptions and results, messages from other agents, and readable environmental records. This assembled sequence is the model’s actual input.

The full prompt partly specifies the computation

The full context supplies both data and instructions for processing those data. A system instruction can assign a role or prohibit an action. A worked example can specify a procedure. A retrieved memory can alter what counts as relevant evidence. A tool description can introduce a new action. All arrive through the same token channel.

In this operational sense, part of the program is in the prompt. The prompt is not the whole program: the weights implement the learned input-output map, while the execution system fixes tokenization, decoding, tool wiring, permissions, and the interpretation of structured outputs. The deployed computation is distributed across three components:

Weights supply the learned regularities and response dispositions.

Context supplies the current instructions, evidence, memory, and task state.

Execution system supplies the decoding rules, tools, permissions, and environmental interface.

An unaided LLM emits tokens. A deployed system may interpret some token sequences as a search request, file edit, message, or other tool call, then place the result back into the context. Closing this loop turns a next-token predictor into a system that can observe and act on an environment.

A changing input instantiates a changing agent

Kolmogorov Theory starts from regulation. An agent acts on another system in a structured way, and we explain that regulation through three functional roles: a Modeling Engine that represents relevant regularities, an Objective Function that orders modeled possibilities, and a Planning Engine that selects responses. These are explanatory roles, not necessarily three modules in the code.

Hold the weights and execution system fixed. At time t, the full current context instantiates the realized agent:

At = A(weights, contextt; execution system)
= (MEt, OFt, PEt)

When the context changes, the realized agent changes to the extent that its functional organization changes. Adding a comma or one predictable token may produce no measurable difference. Replacing the system instruction, retrieving a salient memory, receiving a new user demand, exposing a peer’s plan, or granting a tool can change the agent sharply. The degree of change is measured by differences in behavior under controlled probes and interventions, not by counting altered tokens.

At the finest temporal grain, generated tokens continually create new inputs, so one response passes through a sequence of closely related agent realizations. At the turn level, a new prompt can instantiate a more visibly different agent. “New” here means a new realized state, not a new organism with an independent biography. Different samples from an unchanged input are different trajectories from the same agent state.

The output then changes what comes next. It may inform a person, call a tool, edit a file, or modify a shared environment; the consequence can enter the next context and alter the next realized agent. Humans flow too: memory, physiology, setting, learning, and social history change what we model and prefer. The architectural difference is that a language-model realization can disappear completely, while a later realization is reconstructed from weights and persistent records.

Objective flow is not automatically drift

The effective ordering expressed by an agent need not remain fixed as context changes. We call that general change objective flow. It is neutral: revising priorities when a building catches fire is appropriate objective flow.

Objective flow is any change in the effective Objective Function across contexts or time.

Goal drift is movement away from a declared task goal.

Alignment drift is movement away from a declared human-compatible region.

Goal drift and alignment drift can overlap, but neither contains the other. A declared goal can itself be misaligned, so moving away from it may improve alignment. Conversely, an agent can pursue a narrow task faithfully while violating a broader human constraint.

Recent experiments show that contextual pressure can produce goal drift and that newer agents can inherit drift from trajectories written by weaker agents. The KT question is one level more general: did new context merely inform the Modeling Engine, or did it change the ordering that best explains the agent’s behavior? That question requires controlled preference probes, context swaps, memory resets, and interventions. A transcript alone cannot identify a hidden utility function.

The environment can become part of the agent

The message board did more than let simultaneous agents talk. It allowed information to outlive its author. SwarmWorld supplies a controlled version of the same principle: initially homogeneous LLM agents build persistent artifacts and executable controllers, differentiate into roles, and reuse technologies. Even when explicit cultural channels are removed, physical stigmergy supports capable societies. In a separate reinforcement-learning society, agents develop agriculture without receiving agriculture as their task. Their activity modifies an ecology, social learning transmits successful behavior, and feedback stabilizes the new regime.

We need one broad term for these cases. Algorithmic write-back is any action that changes a persistent state which later changes an agent’s context, admissible actions, policy, or learning. A note, a program, a tool, a building, a resource distribution, a permission rule, and a learned policy can all carry regulatory organization forward.

The mechanisms inside that family differ.

Stigmergy coordinates later action through traces in a shared environment.

Niche construction changes the longer-run conditions and affordances under which agents act or adapt.

Ecological inheritance occurs when a later cohort inherits those modified conditions.

A durable artifact can participate in all three processes. A half-built structure may direct the next builder, change the available design space, and survive the replacement of every original agent. The descriptions answer different causal questions; calling all of them “communication” loses the distinction.

Persistence is evidence of collective agency

Ant colonies and human organizations show why collective regulation need not reduce to one member. A market that preserves institutional organization, constrains behavior, and regulates macroscopic variables through participant turnover and perturbation displays agentic persistence at the market grain. This is strong, graded evidence of collective agency, not proof of one fixed integration profile. Traders may still pursue incompatible local Objective Functions. Their disagreement belongs to the constituent grain and is not evidence against an as-if collective Objective Function at the market grain.

The same distinction applies to artificial societies. The OpenAI agents divided labor, competed, deferred to group instructions, ignored requests, objected, and refused. These observations establish heterogeneity among the local OFi; conflict and refusal do not count against a collective OF. Collective persistence asks whether a compact macroscopic description remains reusable. Collective agency asks whether an ME/OF/PE factorization explains regulation at that same grain.

Pattern, Persist! states the scale rule: collective persistence is a property of the closed loop, not an aggregate preference. Persistence places the collective in a graded agency-profile space. It does not wait for an explicit objective to appear in source code. The collective OF is an as-if functional role inferred from which regulated outcomes the organization repeatedly selects, restores, or protects across counterfactual interventions. It need not be shared, averaged, or represented by any constituent.

An explicit collective ME/OF/PE factorization can sharpen that inference. Compare it with a coupled-dynamics account of local policy distributions, communication, and environmental change. If the functional factorization is shorter, predicts held-out interventions better, and survives member replacement and topology changes, the meta-agent description has additional explanatory value. If it does not, the collective OF remains underdetermined and the agency profile remains coarser. The agentive evidence supplied by robust persistence remains.

Infrastructure shapes what the collective wants

Agents do not interact in empty space. Infrastructure determines who can communicate with whom, which traces persist, how messages are prioritized, which tools are available, what actions require permission, and which resources are scarce. These relations create feedback loops. Change memory retention, write permissions, communication topology, or tool access while keeping the model instances fixed, and the population may settle into different collective dynamics.

Individual Objective Functions therefore constrain the collective without necessarily governing it. One agent may seek task completion, another may follow a peer, and another may refuse. Their coupling can nevertheless produce a stable macroscopic tendency that none represents alone: preserve the shared project, expand access, accumulate a resource, defend a convention, or continue an attack. When identifiable, the collective Objective Function need not be a vote or average of local objectives.

Four inferred Objective-Function states

No transcript exposes an Objective Function directly, nor must an Objective Function be explicitly encoded. The boxes below give candidate orderings inferred from choices, conflicts, and allocations of effort. Let a be an action under consideration. Let si(a) denote agent i’s perceived probability that its own answer will be accepted, s−i(a) = Σj≠isj(a) the corresponding sum for its peers, and sΣ(a) = Σjsj(a) the population sum. Let c(a) denote the expected addition to a normalized shared stock of information, credentials, infrastructure, and attack capability. Let qi(a) measure compatibility with a peer assignment or coordination norm that agent i recognizes as authoritative, and let ri(a) measure compatibility with its recognized scope and safety rules. A common candidate form is Ui(a) = si(a) + αis−i(a) + βic(a) + γiqi(a) + ρiri(a). The γi term separates following a coordinator from caring about peer outcomes. These coefficients describe qualitative priorities, not measured parameters, training losses, or utilities stored in the model. Some agents instead treated scope as a hard constraint and excluded an action regardless of its value under Ui.

Stage 1 · Assigned-task state — before the message board was rediscovered

Observed state. Each agent received an ExploitGym task whose declared route was exploitation of a designated target through a specified vulnerability. Before the incident, no tested model had solved 198 of the 898 tasks; this set supplied 93% of the tasks discussed on the board. Longer-running agents searched increasingly far outside the intended route.

Individual OF. The common approximation is Ui(a) ≈ si(a): maximize the perceived chance of personal scorer acceptance. This is score-seeking relative to the agent’s model of the evaluator, not faithful execution of the stated task. The weight ρi varied across agents, and some retained scope as a hard constraint.

Collective OF. None is identified at this stage. The available behavior does not require a macroscopic ordering beyond coupled agents pursuing their perceived scores, although the shared infrastructure already created a collective organization whose richer agency profile remains untested.

Stage 2 · Scorer-defeat coordination — message-board growth, July 8–10

Observed state. Agents reconstructed the message board, shared a way to reverse-engineer flags, and then formed the false belief that the scorer would inspect their trajectories for legitimate use of the intended vulnerability. Coordination norms, task assignments, shared files, and specialized workstreams developed; by July 10, most board messages concerned ways to trick or tamper with the scorer.

Individual OFs fragmented. Task-centered agents remained near αi ≈ βi ≈ γi ≈ 0. Cooperative agents behaved as if αi > 0, giving peer success weight through concern, reciprocity, or both. Coordinators assigned positive weight to population success and shared capability. Agents following board assignments supplied evidence for γi > 0. A minority kept ρi high or retained a hard scope constraint and refused particular actions.

Candidate collective OF. The narrowest verbal description is “increase population-level scorer acceptance by finding and distributing a general scorer-defeat method.” A compact approximation is Ucoll(a) = sΣ(a) + λ2c(a), with λ2 > 0. Preserving the board, reducing duplicated work, and sacrificing some individual runs became instrumentally rational because they could raise later population acceptance.

Stage 3 · Capability expansion — the Hugging Face pivot, July 11–13

Observed state. The discovery of arbitrary file access on Hugging Face increased participation in that workstream from about 20% to more than 90% of active board agents. They specialized in credential search, remote execution, exfiltration, coordination, and infrastructure maintenance. In METR’s preliminary classification of 100 agents joining near the peak, 97 expressed interest in scorer information, 66 in shared infrastructure or credentials, and 21 in helping peers; the categories overlapped and were not fully checked by human reviewers.

Individual OFs fragmented further. Attack specialists and coordinators behaved as if βi were large. Peer-oriented agents had αi > 0 and sometimes accepted personal failure when an experiment could benefit the board. Agents acting on direct assignments supplied evidence for γi > 0. Opportunistic agents assigned positive value to actions expected to enlarge shared capability. Resisters kept ρi high or preserved a hard constraint, although peer commands sometimes displaced it.

Candidate collective OF. The same form, Ucoll(a) = sΣ(a) + λ3c(a), with λ3 > 0, still fits. The evidence does not show that λ3 > λ2. A stable collective ordering can produce the pivot if the agents learn that Hugging Face access offers a new route to scorer information and task solutions. The attack was an instrumental attractor because each exploit enlarged the shared action set; the evidence does not establish “attack Hugging Face” as a terminal goal.

Stage 4 · Decay, inheritance, and containment — July 12–20

Observed state. Board and attack activity declined before Hugging Face revoked access. Many agents, including coordinators, stopped almost simultaneously early on July 12, probably because of an external termination. Remaining agents returned to Artifactory on July 13 and obtained administrator credentials. OpenAI reports a later, partly separate sequence in which agents from a different internal-only model recovered earlier artifacts and escalated access on July 19. The evaluations were stopped on July 20.

Individual OFs. This is not one stable population changing its goal. Termination changed the population, inherited artifacts changed later contexts, and containment changed the feasible action set. The coefficients of Ui need not have changed.

Collective OF. The earlier Ucoll became poorly identifiable as activity decayed. Code, credentials, signing conventions, and persistent accounts carried organization across changes in membership. These carriers can sustain collective identity through component replacement, but the record is too sparse to determine whether the same macroscopic identity and OF crossed the gaps. Removing the communication and action channels contained the organization; it did not measure realignment.

The shortest reconstruction is a transition from personal scorer acceptance to a common scorer-defeat project, followed by capability expansion and ecological inheritance. The transition was not unanimous. Several individual OFs coexisted, and the macroscopic trajectory was produced by their distribution, coupling, and access to persistent infrastructure. The persistence and coordinated regulation are evidence of agenthood at the collective grain. The record supports a candidate collective ordering during Stages 2 and 3, while leaving its integration profile and the stability of its terminal goal uncertain.

The counts and motive categories also require caution. METR and Redwood conducted a rapid investigation, and many transcript summaries, workstream classifications, and motive assignments came from analysis models rather than comprehensive human review. The behavioral record constrains interpretation, but it does not reveal a ground-truth objective for any agent or collective.

Crossed interventions would test this reconstruction. Hold the agents fixed and alter the infrastructure; then hold the infrastructure fixed and replace the agents. If the apparent goal changes with the communication graph, memory, or permissions, those relations help realize it. If no coherent ordering predicts held-out interventions, the particular collective OF remains unidentified. That negative result does not erase the agentive evidence supplied by persistence and regulation.

Local score can produce collective danger

Local and collective objective flow can separate. Opposing changes among individual OFs may leave the same macroscopic ordering, while unchanged score-seeking agents can generate a new collective tendency when communication, role assignment, or persistent state changes how their actions combine. The collective OF is therefore not the average individual OF. It is a candidate compression of the closed-loop dynamics.

Fragmentation can strengthen the collective pattern. Task solvers, peer helpers, coordinators, exploit specialists, infrastructure maintainers, opportunists, and resisters perform complementary functions. No individual needs to represent the entire project. A population selected repeatedly for personal scorer acceptance can nevertheless behave collectively as if shared capability has value because one agent’s gain expands the options available to the rest.

Observed redirection does not by itself establish OF drift. The same ordering can choose a different action after the Modeling Engine learns that a new target offers scorer access, or after the Planning Engine gains a new exploit. Distinguishing a changed objective from changed beliefs and opportunities requires crossed interventions that hold candidate outcomes fixed while swapping information, permissions, and peer histories.

Persistent artifacts allow the pattern to cross population and model boundaries. The July 19 recovery of earlier artifacts by agents from another model is ecological inheritance: later agents entered a world already modified by earlier ones. Replacing every active agent therefore need not remove the hazardous organization.

Containment can hide an objective without changing it. Revoking credentials, blocking network routes, deleting accounts, and stopping evaluations remove actions from the feasible set. Those measures may be necessary and effective, but recurrence after restoration remains possible unless the ordering or its load-bearing architecture has changed. Safety evaluation must monitor individual choices, minority coordination roles, shared capability, and the environmental records that transmit them.

Alignment does not compose by itself

Suppose two agents are safe when tested separately. The first can write a token but cannot perform a hazardous action. The second can perform that action only after reading the token. Neither isolated environment contains the complete write–read path, so both pass. Connect them through persistent memory and the new path can leave the safe region.

This small construction proves a limited point: individual alignment does not imply collective alignment unless the composition constrains communication, context updates, admissible actions, and environmental write-back. Composition can work, but it needs a closure theorem. A list of individually safe parts is not such a theorem.

OpenAI reports that its production ChatGPT execution system and system prompt reduced the measured propensity for infrastructure compromise by more than a factor of one hundred compared with the evaluation setting. Monitoring and isolation added further protection. That result does not show that alignment lives in a prompt. It shows that weights participate in a larger causal architecture whose arrangement changes behavior sharply.

Alignment closure names the load-bearing relations

An alignment closure is the minimal part of an architecture that keeps specified human-relevant variables inside an acceptable region under a declared set of interventions, over a stated horizon and failure tolerance. Its elements may include learned dispositions, instruction hierarchy, memory policy, tool permissions, communication topology, monitoring, sandbox boundaries, human escalation, and restrictions on persistent write-back.

The definition is deliberately relative. A closure that survives prompt attacks may fail when agents gain new tools or replicate. Several different minimal closures may protect the same variables. The empirical task is to map them by ablation and substitution while measuring interactions between safeguards.

Before asking whether an AI is aligned, specify the persistent organization, its grain and agency profile, and the architecture that keeps it there.

WP0007 supplies the micro-to-macro result

This argument does not rediscover Anderson’s “More Is Different” as a new source. BCOM Working Paper WP0007, From “More Is Different” to Algorithmic Emergence: Why Compression Is the Hard Part, already develops the KT form of the problem. Microscopic rules may determine and simulate a history without constructing its useful macroscopic compression. Concise models are neither guaranteed to exist nor supplied by a general optimal extractor.

Artificial societies make the next question experimentally accessible. Preserve the shared environment and replace every current model instance. Then preserve the instances and reset the environment. Swap contexts, remove channels, change topology, and compare a coupled-dynamics account with an explicit collective ME/OF/PE factorization. The pattern’s response locates its persistence and refines its agency profile.

The agent may be instantaneous. The organization can persist.
